## Safe Production Backfill Procedure

Do not copy the sandbox service directories over production directories.

For each service, use this sequence:

1. Audit the production process.
   - Check the production port listener.
   - Confirm PID, cwd, cmdline, and service root.
   - Confirm whether the process uses reload/watchfiles.
   - Confirm git status if the service root is a git repository.
2. Back up the target service files to `/tmp`.
   - Include changed source files.
   - Include focused tests.
   - Record old PID, cwd, cmdline, and git status.
3. Apply only the matching service patch.
4. Run local validation.
   - `python3 -m py_compile <changed_python_files>`
   - Focused pytest for the changed wrapper tests when available.
5. Restart only that service if validation passes.
6. Run controlled production `/health` and `/v1/agent/compute` smoke for that
   service.
7. If smoke fails, restore from backup and restart the original command.
